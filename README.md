---

## 📌 Sobre o Projeto

O **BeeCrowd** é uma plataforma que oferece centenas de problemas de programação. Aqui você encontrará resoluções focadas em:
- Estruturas de repetição e condicionais.
- Manipulação de arrays e strings.
- Matemática computacional.
- Estruturas de dados complexas.
